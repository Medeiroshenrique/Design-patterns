# 🛠️ Design Patterns

Welcome to the **Design Patterns** repository! 

This project serves as a practical, code-focused catalog of software design patterns. It features implementations in **Java** and **C#**, demonstrating how to apply these solutions effectively while adhering to **SOLID** principles and **Clean Code** practices.

## 🚀 About This Project

Design patterns are proven solutions to common software design problems. By implementing them here, this repository explores how to build flexible, reusable, and highly maintainable object-oriented architectures. 

Because different patterns sometimes shine in different contexts, some patterns in this repository are built in Java, while others are built in C#. 

*Note: This repository is actively growing. Patterns will be checked off and tagged with their respective language(s) as they are added.*

## 📚 Patterns Catalog

### 🏗️ Creational Patterns

- [x] **Singleton** — `C#`

- [x] **Factory Method** — `Java`
